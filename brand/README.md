# brand

Marketing source material that the site does not serve: posters, print
artwork, social media originals.

`poster-facebook.png` is a 1024×1536 promotional poster with the logo,
headline, feature icons and size badges already drawn into it. It is not usable
as a hero image — the text is pixels, so it cannot be translated or read by a
search engine, and it is Arabic-only. `web/public/brand/hero.jpg` is the model
photograph cropped out of it.
